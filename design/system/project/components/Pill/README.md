# Pill

Buttons are pills. `.pill` is the primary action: paper fill, ink chevron disc that nudges right on hover (spring easing). `.pill.dark` is the same on light ground. `.btn` is the outlined secondary, `.btn.danger` is coral and only for destructive actions (Revoke tab).

Minimum height 48px (`.btn.small` 44px). Labels say exactly what happens. A busy button shows a spinner and what to do next ("Check your wallet").
