# Button

Square, mono, sentence case. Three kinds:

- `.btn.primary`: ink fill, for the one main action in a view ("Open a tab"). Hover turns it stamp red.
- `.btn`: outlined, for everything else.
- `.btn.danger`: stamp outline, for destructive actions only ("Revoke tab", "Close tab").

Minimum height is 48px (`.small` is 44px). Labels say exactly what happens. A busy button shows a spinner and what to do next ("Check your wallet").
