# Console

The console shows what an agent is doing right now: a title bar, the live balance, a scrolling log, actions. Ink surface inside the graphite page.

Each request is two lines: the request (`GET url → 402 amount`), then TAB's verdict, dim when signed and coral (`.no`) when refused, always ending with what happened ("nothing signed").

Use it only for live activity: the landing demo and the dashboard's test agent.
